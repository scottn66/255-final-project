## How we run

Phase-kanban. One PLAN.md phase = one ticket = one sprint. **WIP = 1** implementation ticket.

1. Read [BOARD.md](../BOARD.md). Pull the `ready` card.
2. Put your name (or model + date) on **Owner**. Set `in_progress` on the board **and** the ticket **before** coding.
3. Paste the ticket’s pickup prompt into an AI, or implement it yourself.
4. Stop at the ticket’s acceptance criteria. `pytest -q`. Move to `review` / `done`. Write 5 lines in the sprint log.

Do not start a `backlog` card while a `ready` / `in_progress` card exists.

## Definition of done

- Ticket checkboxes done
- `pytest -q` green
- No banned attention APIs
- No data download unless the ticket says so
- BOARD.md updated
