# 1.20 Copy vs change

**Layer:** Plan · **Up:** [1.00](1.00-plan.md) · **Prev:** [1.10](1.10-defaults.md) · **Next:** [1.30](1.30-experiment.md) · **Spec:** PLAN.md A.3

| Module | SSFT paper (copy) | SSFT-Wave (change) |
|--------|-------------------|--------------------|
| Spectral `φ` | Per-scalar embed → D | Shared `Linear(1, D)` (already tied) |
| Spectral PE | Learned `P ∈ R^{C×D}` by **band index** | Sinusoidal PE of **λ (nm)** |
| Spectral MHSA | 1 block, 4 heads, residual+FFN | Copy, written from scratch |
| Spatial stem | `Conv2d(C, D, 1)` — **fixed C** | Tied `Conv2d(1, D, 1)` + masked mean |
| Spatial block | 3×3 + BN + GELU | Copy |
| Fusion | Spatial Q, spectral K/V, 4 heads | Copy, from scratch |
| Head | Adaptive pool + 2-layer MLP | Copy; aux off |
| Forward | Implicit fixed C | `forward(cube, wavelengths, band_mask)` |

**Index-PE baseline (SSFT-2 / SSFT-6 family):** packed positions `0 … C−1` of the *current* tensor, not a `C_full` sensor table. That way a complementary subset of the same length reuses the wrong rows — the failure λ-PE is supposed to fix.

**Vanilla ViT (later, [2.30](2.30-later-sprints.md)):** first linear **collapses bands**, `C` baked in. Dropped bands are zero-filled to `C_train`.

Skip from LESSViT: LESS Attention, Kronecker factorization, HyperMAE, SSRoPE (stretch), SpectralEarth pretrain.
