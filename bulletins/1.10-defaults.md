# 1.10 Locked defaults

**Layer:** Plan · **Up:** [1.00](1.00-plan.md) · **Next:** [1.20](1.20-copy-vs-change.md) · **Spec:** [PLAN.md](../PLAN.md) (locked table)

Changing any row is a **group decision**. Edit PLAN.md first, then this note.

| Decision | Lock |
|----------|------|
| Input | Labeled-center **16×16** patches (not whole-cube classification) |
| Split | **Spatial block split only** (discard patches that cross train/test cells) |
| Width | **D = 64**, **4 heads** |
| Depth | **1** spectral MHSA + **1** spatial conv block + **1** cross-attn fusion |
| Downsample | **s = 8** max-pool (if a later patch is `< 8`, set `s = patch_size`) |
| Fusion | Spatial tokens **Q**, spectral tokens **K/V** |
| λ-PE v1 | Sinusoidal 1D on λ in **nm**, internally **÷ 1000** (microns) |
| Tied projection | Yes, on every C-mixing layer (Wave path) |
| Aux heads | Off until a later ticket (`λ_aux = 0.05`) |
| Attention | From scratch. No `nn.MultiheadAttention` / timm / HF ViT blocks |

**Why patches, not cubes:** SSFT’s paper is cube→one class. Indian Pines / Pavia U are **pixel-labeled** scenes. We keep SSFT’s modules and feed 16×16 patches labeled by the **center pixel**.
