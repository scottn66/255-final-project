# Tickets

One file per sprint. Status on the card **and** on [`../BOARD.md`](../BOARD.md) must match.

| Status | Meaning |
|--------|---------|
| `backlog` | Not pulled. Do not start if a `ready` card exists. |
| `ready` | Next sprint. Anyone/any AI may pull it. |
| `in_progress` | Owned. Do not take it. |
| `review` | Implementer thinks DoD is met; another person or AI checks PLAN.md. |
| `done` | Merged to the working tree, tests green, board updated. |
| `blocked` | Write the blocker in the ticket body. |
